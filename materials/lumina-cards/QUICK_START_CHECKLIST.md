### 🖨️ Passo 4: Imprimir Cartas Necessárias (15 minutos)

#### Para Aula 1 você precisa:
- [ ] **5 cópias** da Carta A ⚡ (uma por grupo se dividir turma)
- [ ] **Certificados** (quantidade = número de alunos)
- [ ] **Opcional**: Cartaz grande com A (para parede)

#### Como Imprimir:
1. [ ] Abrir arquivo PDF ou PNG da Carta A
2. [ ] Configurar impressora:
   - Papel: A4 ou carta
   - Qualidade: Normal (para economizar)
   - Cor se possível, P&B funciona também
3. [ ] Imprimir frente
4. [ ] **Se tiver tempo**: Plastificar ou colar em cartolina
5. [ ] Recortar seguindo guias

#### Alternativa sem Impressora:
- [ ] Desenhar Carta A à mão em cartolina
- [ ] Fazer 1 carta grande para mostrar para toda turma
- [ ] Escrever certificados à mão (mais pessoal!)

### 🎨 Passo 5: Preparar Ambiente (10 minutos)

#### Espaço Físico:
- [ ] Limpar área central da sala (para movimento)
- [ ] Organizar cadeiras em círculo (se possível)
- [ ] Preparar tapete ou área no chão (para sentar)
- [ ] Verificar ventilação e temperatura

#### Materiais Organizados:
- [ ] Cartas A em local de fácil acesso
- [ ] Certificados prontos para distribuir
- [ ] 5 objetos que começam com A (se for fazer atividade):
  - Exemplos: Avião (brinquedo), Abacaxi (figura), Amor (palavra escrita), Amigo (foto), Árvore (desenho)

#### Tecnologia:
- [ ] Testar áudio da sala
  - Celular funciona? Alto-falante disponível?
- [ ] Abrir YouTube (ou arquivo) com 432 Hz
- [ ] Testar som antes (volume adequado)
- [ ] Ter backup: seu próprio celular com áudio salvo

#### Checklist Final do Ambiente:
- [ ] Espaço livre para movimento? ✅
- [ ] Materiais acessíveis? ✅
- [ ] Áudio funcionando? ✅
- [ ] Ambiente acolhedor? ✅

### 🎵 Passo 6: Ouvir Frequências (5 minutos)

**Objetivo**: Você precisa SENTIR a frequência antes de apresentá-la.

#### Como Fazer:
1. [ ] Sentar confortavelmente
2. [ ] Tocar 432 Hz (buscar "432hz pure tone" no YouTube)
3. [ ] Fechar os olhos
4. [ ] Respirar profundamente
5. [ ] Sentir a vibração no corpo
6. [ ] Imaginar: Como vou apresentar isso às crianças?

#### Reflexão:
- [ ] Que sensação a frequência me traz?
- [ ] Como vou descrever para crianças?
- [ ] Que movimento corporal combina com esse som?

**Dica**: Não precisa ser perfeito. A intenção é mais importante que a precisão!

---

### 🗣️ Passo 7: Praticar Pronúncia (10 minutos)

#### Vogal A:
- [ ] Pronunciar: "AAAA" (como em PAZ, não como em MÃE)
- [ ] Repetir 10x em voz alta
- [ ] Sentir: Boca bem aberta, som vindo do coração

#### Palavra AMOR:
- [ ] Pronunciar: "A-MOR" (ênfase no A)
- [ ] Repetir 10x
- [ ] Adicionar emoção: dizer com amor de verdade!

#### Frase "MI LUMA":
- [ ] Pronunciar: "MI LU-MA"
- [ ] Significado: "Eu sou luz"
- [ ] Repetir 10x com convicção
- [ ] Adicionar gesto: mão no coração

#### Prática Completa:
- [ ] Cantar suavemente: "AAAA-mor, AAAA-mor, MI LUMA"
- [ ] Com movimento: braços abertos para cima (recebendo luz)
- [ ] Imaginar fazendo com as crianças

## 💡 DICAS DE ÚLTIMA HORA

### Se Algo Der Errado:

**Problema**: Áudio não funciona  
**Solução**: Cantar você mesmo(a) no tom mais próximo

**Problema**: Tempo curto
